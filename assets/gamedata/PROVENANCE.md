# Built-in game data

Everything in this folder is compiled into AVION2. At runtime the app makes **no** network requests for data.
The names are NCSoft game content (AION2). Each table's source is listed below. After a game patch, the tables
extracted from the client are rebuilt with `tools/extract_gamedata` (see docs/DEVELOPMENT.md).

| Path | Content | Source | License of the source |
|---|---|---|---|
| `skills/<lang>.json` | Skill id → name (en, de, fr, es, pt, ru, ja, ko) | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: Skill, SkillString and the texts of each language | Game data |
| `npcs/<lang>.json` | NPC code → name, boss / dummy flags (en, de, fr, es, pt, ru, ja, ko) | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: NpcData and the texts. Bosses are the hero and legend monsters and the training scarecrows; dummies are training targets by English name | Game data |
| `field_bosses.json` | Field boss spawn code (map × 100 + n) → NPC code | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: WorldMapFieldNamed and NpcData | Game data |
| `maps/<lang>.json` | Map id → zone name (en, de, fr, es, pt, ru, ja, ko) | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: Map and the texts | Game data |
| `gear_forge.json` | Item → enchant/amplify ladder (chance, pity per fail, Kinah and materials per attempt), English item names | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: Item, Enchant, ExceedEnchant and the English texts | Game data |
| `gear_stats.json` | Item → item level, slot and enchant effect group; per group the stats at each enchant level (cumulative) | Datamined game data (Global client) as published in [aion2hub.com](https://aion2hub.com/tools/build-calculator)'s build planner (its script chunks), fetched 2026-11-02 (`tools/build_gear_stats.py`) | Game data |
| `world/<map>.json`, `world/<map>.jpg` | Zone maps: picture (tiles stitched, half resolution), markers (teleports, hidden cubes, monoliths, gathering, monsters with level/rank/drops, NPCs), regions | Datamined game data and map tiles as published by [aion2hub.com/maps](https://aion2hub.com/maps), fetched 2026-10-14 (`tools/build_maps.py`; marker icons, the game's own, via `tools/build_map_icons.py`). | `dungeon_names.json` | Dungeon id → English name with the difficulty or stage ("Krao Cave (Exploration)"), for group-finder rooms | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: Dungeon, PartyDungeonLevel and the English texts | Game data |
| `pets.json` | Every pet kind: its name in the 8 languages, the souls the pet takes and its soul item; the souls each pet level takes (25 to level 2, 75 to level 3) | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: VehicleList, VehicleLevel, Item and the texts | Game data |

| `servers.json` | Server id (as in player records) → name, short name, faction, region; all 106 servers | NC's public server list, `aion2.plaync.com/en-us/api/gameinfo/servers` for each region, fetched 2026-11-01 (`tools/build_servers.py`) | Game data |
| `classes/<class>.png` | Official class emblems (256×256) | NCSoft's public armory CDN, `assets.playnccdn.com/static-aion2/characters/img/class/class_icon_<class>.png` | NCSoft artwork |
| `bosses/<model>.png`, `bosses/bosses.json` | Boss portraits (128×128, one per boss model) and which boss shows which: 52 of the 85 field bosses, all 5 world boss rows of the Timers page | The game's portraits as published by [aion2hub.com](https://aion2hub.com/tools/world-bosses) (world boss page and the "por" of named monsters in its [map](https://aion2hub.com/maps) data), fetched 2026-11-04 (`tools/build_boss_images.py`). | `recipes.json` | Crafting recipes (product, batch size, profession, Elyos or Asmodian side, category, Kinah fee, materials, combo product and chance), the names of the items they use, and which bound items stand in for a material. 550 recipes (with the True Dragon and Star Dragon gear), 900 items | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: CraftRecipe, CraftComponentReplacement, Item and the English texts | Game data |
| `stat_rates.json` | What each of the 6 attributes and 10 deity stats converts into, per point (derived stat, English name, percent per point), for the Forge's stat calculator. Light [Ariel] and Darkness [Azphel] have no conversion in the data | AION2 client tables (Global/EU client of 2026-11-04), extracted with `tools/extract_gamedata`: PcStatSecond and the English stat names. Rates checked against the official site's character pages: 0.1 % per point for every input | Game data |
| `skillicons/*.png`, `skillicons/index.json` | Skill icons (64×64) and base skill id → icon, all 9 classes | Pictures: NCSoft's public CDN, `assets.playnccdn.com/static-aion2-gamedata/resources/<icon>.png`. Which skill has which icon: the official site's character skill lists (`aion2.plaync.com/api/character/equipment`, Global and Korean characters), fetched 2026-11-04; chain steps and other skills the site doesn't list from [SkeeveAN/Aion-DPS-Meter](https://github.com/SkeeveAN/Aion-DPS-Meter) `Backend/src/data/aion2/skill_icons.json`, commit `63ef1f686d1bcdfbef9233eb5e58abf379156ea5` (`tools/build_icons.py`) | Game artwork; SkeeveAN's table MIT (`licenses/SkeeveAN-LICENSE-MIT.txt`) |
| `itemicons/*.png`, `itemicons/index.json` | Item icons (48×48) and item id → icon: equipment, wings, currencies, stones, materials | Pictures: NCSoft's public CDN as above, or aion2hub's copy (`aion2hub.com/api/icon/items/<id>`) where the CDN has none. Which item has which icon: SkeeveAN/Aion-DPS-Meter `item_icons.json` (same commit), the gear the official site shows on characters, and [aion2hub.com](https://aion2hub.com) item pages, fetched 2026-11-04 (`tools/build_icons.py`) | Game artwork; SkeeveAN's table MIT |

## Overrides

Files named `skills.json`, `npcs.json`, `field_bosses.json` or `maps.json` in `%AppData%\AVION2\data` (or the
folder given with `--data`) replace single built-in tables. PNGs in `%AppData%\AVION2\classes` replace single
emblems; PNGs in `%AppData%\AVION2\bosses` named after an NPC code (`2100003.png`) or a world boss row
(`wb-executors.png`) replace or add boss portraits; PNGs in `%AppData%\AVION2\skillicons` and `%AppData%\AVION2\itemicons`, named
after the skill or item id (`18010000.png`) or the icon (`ICON_CH_SKILL_001.png`, as in `index.json`), replace single
icons.
